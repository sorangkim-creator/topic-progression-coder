        Shortcuts

        1. Draw the double-coding sample

        Reviews are sampled per language (stratified). The same seed always gives the same sample.

        2. Compare two coders

        Load the JSON exported by each coder. Sentences are matched by review ID and sentence number; segmentation must be identical.

        3. Disagreements & consensus

        Consensus decisions are stored separately from each coder's data (browser storage) and can be exported.

        Privacy All data stays in this browser. Nothing is uploaded or sent anywhere; files are read locally and saved only to this browser's storage.

        Import reviews (CSV)

        Columns: review_id, lang (ko/ja/zh), text. UTF-8. Sentences are split automatically and can be merged/split in the coding view.

        Project (JSON)

        Work is auto-saved in this browser. Export JSON regularly as a backup and to share with the reliability check.

        Export coded data (CSV)

        One row per sentence, UTF-8 with BOM so Excel shows Korean/Japanese/Chinese correctly.
